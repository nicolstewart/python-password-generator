# 🔐 Password Generator (Python)

## Overview
This is a simple Python password generator that creates secure, random passwords based on user-defined criteria.

The project was built to strengthen my understanding of Python fundamentals and logic building.

---

## Features
- Generates secure random passwords
- Customisable password length
- Uses letters, numbers, and symbols
- Simple command-line interface

---

## How It Works
The program builds a pool of characters (letters, digits, symbols) and randomly selects characters to generate a secure password of the desired length.

---

## Concepts Practised
- Variables
- Loops
- Conditionals
- Functions
- String manipulation
- Python `random` module

1. Make sure Python is installed
